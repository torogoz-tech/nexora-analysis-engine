# Security

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues. Use the repository's **Security → Advisories → Report a vulnerability** flow to contact maintainers privately. If GitHub does not offer private reporting for this repository, contact a repository maintainer privately.

Include the affected package and version, impact, reproduction steps, and a suggested mitigation when available. Do not include credentials or personal data in the report.

Public releases must be checked for secrets, internal data, private URLs, generated artifacts, and unsafe examples before publication.
